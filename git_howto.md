# Подсказка по гиту

## Инициализация репозитория

```sh
git init
```

## Статус репозитория

```sh
git status
```

## Версия Git

```sh
git --version
```

## Добавление файла в репозиторий 

```sh
git add
```

## Сохранение с сообщением 

```sh
git commit -m "Commit message"
```

## История коммитов 

```sh
git log
```

## Открывает конкретное сохранение 

```sh
git checkout <commit>
```
